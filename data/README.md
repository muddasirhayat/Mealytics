# Mealytics Quick Meals Dataset

## Nutrition Data Sourcing
The meal records in `quickRecipes.json` are derived from standard nutrient profiles established by **USDA FoodData Central** (Foundation Foods and SR Legacy data) for whole and minimally processed food items:
- Lean poultry, beef, and seafood items (e.g., roasted chicken breast, wild Atlantic salmon, cod, shrimp, sirloin).
- Whole grains and legumes (e.g., quinoa, brown rice, rolled/steel-cut oats, black beans, lentils, chickpeas, edamame).
- Fresh vegetables and fruits (e.g., broccoli, asparagus, spinach, sweet potatoes, blueberries, apples, avocados).
- Dairy and eggs (e.g., nonfat Greek yogurt, low-fat cottage cheese, whole eggs, egg whites).

## Units & Consistency
- **Calories**: kcal
- **Protein**: grams (g)
- **Carbohydrates**: grams (g)
- **Fat**: grams (g)
- **Fiber**: grams (g)
- **Serving Size**: Described with standard kitchen unit and gram weight equivalent.

## Offline First
This dataset is bundled locally and requires **zero runtime network requests or API keys**, ensuring instant load times and 100% privacy/offline capability.
